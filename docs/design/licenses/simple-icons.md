# Simple Icons

The X, Facebook, Instagram and YouTube icons in `resources/views/public/social-icon.blade.php`
come from [Simple Icons](https://simpleicons.org/) 16.34.0, released under CC0-1.0 (public
domain). The LinkedIn mark there is a plain "in" glyph drawn for this site, because Simple
Icons no longer includes LinkedIn. Brand names and logos belong to their owners; using them
to link to the lab's own profiles is normal use.
